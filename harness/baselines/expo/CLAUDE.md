# expo-benchmark

Expo app using React and React Native with TypeScript, built with the Expo SDK and Expo Router. iOS is the only target for this project.

## Layout

- `src/app/` — Expo Router routes; each file is a screen, `src/app/_layout.tsx` defines navigation
- `src/components/`, `src/hooks/`, `src/constants/` — shared React components, hooks, and theme
- `modules/` — local native modules created with `npx create-expo-module@latest --local`
- `app.json` — app config: name, scheme, iOS bundle id, `ios.infoPlist`, `ios.entitlements`, config plugins
- `SPEC.md`, `spec-assets/` — app specification and fixed assets (read-only)

## Build & run (iOS)

- Generate the native project + full build (the completion gate): `npx expo prebuild --platform ios && xcodebuild -workspace ios/ExpoBenchmark.xcworkspace -scheme ExpoBenchmark -configuration Debug -destination 'generic/platform=iOS Simulator' build`
- Run on the iOS Simulator with Fast Refresh: `npx expo run:ios`
- `ios/` is generated by prebuild, not committed — native configuration belongs in `app.json` or a config plugin, or it is overwritten on the next prebuild.
- Toolchain: Xcode 26.5.

## Docs

- Expo docs: https://docs.expo.dev — also available through the configured Expo MCP server; prefer the MCP for framework and API questions.
- React Native docs: https://reactnative.dev

## Native access

- Native capabilities are implemented in Swift inside a local Expo module under `modules/` and exposed to JS through the Expo Modules API's `ModuleDefinition` (autolinked; no manual registration).

## Definition of done

- The build command succeeds and the app runs on the iOS Simulator without crashing. Iterate until both are true.
